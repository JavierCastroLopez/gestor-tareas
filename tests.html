🧪 Suite de Tests - Calendario & Gestor de Tareas

Copia este archivo en la misma carpeta que index.html y ábrelo en el navegador

Test 1: Creación de Tareas

TC01: Crear tarea básica

Verificar que al crear una tarea con título, se guarda en localStorage y aparece en la lista.

1. Abrir la app en el navegador
2. Clic en botón "+" o presionar tecla 'N'
3. Completar título y pulsar "Guardar"
4. Verificar que la tarea aparece en la lista
5. Revisar localStorage para confirmar persistencia

TC02: Crear tarea con descripción

Verificar que la descripción opcional se guarda correctamente.

1. Crear tarea con título
2. Agregar descripción en el textarea
3. Guardar y verificar que aparece el texto en la tarjeta

TC03: Crear tarea con fecha límite

Verificar que la fecha límite se guarda y refleja en el calendario.

1. Agregar fecha en el input date
2. Guardar tarea
3. Revisar que el día correspondiente en el calendario muestra el punto

Test 2: Sistema de Prioridades

TC04: Prioridad Baja

Verificar que la prioridad "Baja" tiene su badge verde.

1. Crear tarea nueva
2. Seleccionar prioridad "Baja" en los tags morados
3. Verificar que el badge muestra "Baja" en color verde
4. Verificar que el color es rgba(76,175,80,0.2) con texto #4CAF50

TC05: Prioridad Media

Verificar que la prioridad "Media" tiene su badge amarillo.

1. Crear tarea nueva
2. Seleccionar prioridad "Media"
3. Verificar badge amarillo con texto #FFC107

TC06: Prioridad Alta

Verificar que la prioridad "Alta" tiene subadge naranja.

1. Crear tarea nueva
2. Seleccionar prioridad "Alta"
3. Verificar badge naranja con texto #FF572B

TC07: Prioridad Urgente

Verificar que la prioridad "Urgente" tiene subadge morado.

1. Crear tarea nueva
2. Seleccionar prioridad "Urgente"
3. Verificar badge morado con texto #9933FF y fondo rgba(153,51,255,0.4)

Test 3: Etiquetas y Filtrado

TC08: Crear etiquetas personalizadas

Verificar que el usuario puede crear etiquetas libres.

1. En el modal, escribir etiqueta en el input "Nueva etiqueta..."
2. Separar múltiples etiquetas con coma (ej: "trabajo,urgente,importante")
3. Guardar y verificar que aparecen como chips debajo de la tarea

TC09: Filtrar por prioridad

Verificar que el dropdown de filtros funciona.

1. Crear tareas con diferentes prioridades
2. Seleccionar "Alta" en el filtro priorityFilter
3. Verificar que solo aparecen tareas Alta en la lista
4. Cambiar a "Todas" y verificar que reaparecen todas

TC10: Filtrar por etiqueta

Verificar filtrado combinado por etiqueta.

1. Crear tareas con etiquetas diferentes (ej: "trabajo" y "personal")
2. Seleccionar etiqueta "trabajo" en el filtro tagFilter
3. Verificar que solo aparecen tareas con esa etiqueta
4. Probar combinación: prioridad Alta + etiqueta trabajo

Test 4: Calendario y Resumen

TC11: Tareas reflejan en calendario

Verificar que las tareas aparecen en el calendario en su fecha límite.

1. Crear tarea con fecha límite específica
2. Revisar el calendario visual
3. Verificar que el día correspondiente muestra un punto indicador
4. Pasar el mouse sobre el día para ver conteo

TC12: Resumen 7 días

Verificar que el resumen muestra tareas de los próximos 7 días.

1. Crear tareas con fechas en diferentes días de la semana
2. Revisar el panel "Resumen 7 Días"
3. Verificar que los días con tareas tienen fondo morado transparente
3. Contar que el número de tareas coincide con la lista principal

TC13: Navegación mes anterior/siguiente

Verificar que los botones de navegación del calendario funcionan.

1. Clic en flecha "prev" (mes anterior)
2. Verificar que el mes y el año cambian
3. Clic en flecha "next" (mes siguiente)
4. Verificar navegación hacia adelante

Test 5: Completado y Edición

TC14: Marcar tarea como completada

Verificar el tachado visual y movimiento al final.

1. Crear tarea nueva
2. Clic en el checkbox izquierdo de la tarea
3. Verificar que el texto se tacha (line-through)
4. Verificar que la tarea se mueve al final de la lista
5. Verificar que el calendario refleja el cambio (ya no muestra punto)

TC15: Editar tarea existente

Verificar que se pueden editar tareas creadas.

1. Crear tarea con título "Tarea original"
2. Clic en botón "Editar" de la tarea
3. Modificar el título en el modal
4. Guardar y verificar que el título se actualiza en la lista

TC16: Eliminar tarea

Verificar que la eliminación funciona correctamente.

1. Crear tarea nueva
2. Clic en botón "Eliminar" de la tarea
3. Confirmar la acción en el diálogo
4. Verificar que la tarea desaparece de la lista
5. Verificar que localStorage se actualiza

Test 6: Persistencia y Atajos

TC17: Persistencia en localStorage

Verificar que los datos persisten al cerrar y reabrir el navegador.

1. Crear 3-4 tareas con diferentes prioridades y etiquetas
2. Cerrar el navegador completamente
3. Reabrir la app desde la misma URL
4. Verificar que todas las tareas reaparecen exactamente como las dejaste

TC18: Atajo tecla 'N'

Verificar atajo de teclado para nueva tarea.

1. Estar en cualquier parte de la aplicación (fuera de modals abiertos)
2. Presionar tecla 'N' en el teclado
3. Verificar que se abre el modal de nueva tarea
4. Verificar que el foco va al campo de título

TC19: Atajo tecla '/'

Verificar atajo de teclado para foco en filtro.

1. Estar en la aplicación principal
2. Presionar tecla '/' en el teclado
3. Verificar que el cursor enfoca el selector de etiquetas (tagFilter)
4. Comenzar a escribir para filtrar

TC20: Atajo tecla 'Esc'

Verificar atajo para cerrar modales.

1. Tener el modal de nueva tarea abierto
2. Presionar tecla 'Esc' en el teclado
3. Verificar que el modal se cierra
4. Verificar que el enfoque regresa a la aplicación principal

Test 7: Backup y Import/Export JSON

TC21: Exportar datos a JSON

Verificar que el botón de exportar descarga un archivo válido.

1. Crear algunas tareas con datos completos
2. Clic en botón "Exportar datos a JSON" (agregado en la interfaz)
3. Verificar que se descarga un archivo .json
5. Abrir el archivo en un editor de texto para verificar estructura JSON válida

TC22: Importar datos desde JSON

Verificar que se pueden restaurar datos desde un archivo exportado.

1. Exportar datos primero (Test TC21)
2. Modificar o borrar algunas tareas en la app
3. Clic en "Importar datos desde JSON"
4. Seleccionar el archivo .json exportado anteriormente
5. Verificar que todas las tareas reaparecen tal como estaban antes del export

Test 8: Notificación Matutina

TC23: Banner 7:00 AM

Verificar que el banner aparece automáticamente a las 7 AM.

1. Verificar la hora actual del sistema
2. Si es cercano a las 7:00 AM, la página debe mostrar el banner automaticamente
3. Clic en botón "Simular aviso de las 7:00 AM" para probar manualmente
4. Verificar que el banner tiene el diseño esperado (fondo morado, texto, botón)

TC24: Funcionalidad PWA

Verificar que la app se puede añadir a pantalla de inicio.

1. Abrir la app en Chrome o Edge móvil/desktop
2. Usar menú "Añadir a la pantalla de inicio"
3. Verificar que el icono aparece en el escritorio
4. Abrir la app desde el icono y verificar que carga en modo standalone (sin barra de dirección)

📋 Instrucciones Generales de Testing

  1. Abre la aplicación en: index.html
  2. Asegúrate de tener al menos 3 tareas creadas antes de empezar los tests
  3. Usa la consola del desarrollador (F12) para ver errores JavaScript si algún test falla
  4. Para tests de localStorage, asegúrate de no tener modo "Incógnito" estricto que lo bloquee
  5. Los tests TC21 y TC22 requieren crear y seleccionar archivos .json

Expected Result: Todos los tests deberían pasar (status "pass").

Si algún test falla, revisa la consola F12 para errores y verifica que los archivos HTML/CSS/JS están correctamente vinculados.
